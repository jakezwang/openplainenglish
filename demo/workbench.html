How to use this with PDFs, images and mobile

This text workshop works in a regular browser. You can paste text you have already extracted from a PDF or image. It does not read files, perform OCR, inspect frames, or access other tabs. Verify extracted text against the original before using it. Scanned text and complex layouts can lose words or punctuation.

Ordinary copy and browser Find use the words currently displayed. Copy original preserves the full input. Printing uses original wording. The public-service glossary is an opt-in editorial pilot; neither glossary has completed independent expert review or a reader-comprehension study.
