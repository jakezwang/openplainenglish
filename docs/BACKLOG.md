## Actions requiring the owner or other people

1. Register/pay for the Chrome Web Store developer account, verify contact details and accept publisher terms.
2. Install the release in real browsers; complete native install/upgrade/import/print checks and capture actual extension screenshots. Prior automation blocks were not bypassed.
3. Complete publisher declarations, submit the package and respond to review; provide the approved store URL afterward.
4. Arrange independent language/domain review and consenting readers. Run the prepared study and analysis on actual records; do not treat synthetic workflow tests as people.
5. Choose a public feedback inbox if email delivery is wanted, and supply any desired additional store memberships or physical test devices.

No participants were recruited or messaged, no accounts purchased, no declarations submitted, no feedback sent, and no independent endorsement or comprehension gain invented.
