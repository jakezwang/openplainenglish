# Store artwork

`promo-small.html` is original promotional artwork for OpenPlainEnglish. It uses the project's cream, green, and Georgia/Arial typography without external assets or network requests.

The rendered **440 × 280 pixel** JPEG is `promo-small.jpg`. To recreate it, open the HTML at 100% zoom and capture the `.tile` canvas at its observed bounds, `(0, 0, 440, 280)`. Check the exported pixel dimensions before using it; a browser viewport override may scale the screenshot differently from its CSS dimensions.

This tile is brand artwork, not an extension screenshot. Capture store screenshots separately from the working interface. The artwork describes the reading aid and its sources, local processing, and open-source code; it makes no clinical-validation or store-approval claim.

Treat rendered assets as submission drafts until the listing is published. The source artwork follows the repository's MIT license.
