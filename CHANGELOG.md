# Changelog

## 0.4.0 — 2026-10-13 (preview)

- Add English/Chinese interface controls, local density and highlight preferences, remembered reading mode, and keyboard commands for toggle and restore. Fresh documents still start disabled; changing preferences alone does not activate page access.
- Add one-occurrence restore, ignore-for-this-page controls, conservative literal/compound boundaries, and matching across supported inline formatting while preserving existing elements and website edits. Count a split phrase once and retain original wording for comparison and print-event handling.
- Provide reviewed feedback text for copy or download without a GitHub account, with selectable-text fallback. Keep explicit GitHub sharing, JSON backup/import and the seven-field local draft schema; preferences are stored separately.
- Expand the health glossary to 112 sourced entries. Health replacement coverage remains 40 explicit pairs across 21 entries. Add a separate opt-in public-service pilot with 8 entries and 14 pairs for the workshop and SDK.
- Add a local paragraph workshop with original/reading comparison, copy controls and no paragraph persistence; a compatibility lab; and a runnable three-condition study with synthetic passages and explicit local results export. Actual participants: **0**; no comprehension or clinical outcome is claimed.
- Package an unsigned Firefox desktop preview and a standalone engine/data SDK tarball alongside the Chromium ZIP. Neither AMO signing nor npm registry publication is implied. PDF text can be pasted after extraction; PDF parsing, OCR, iframe and shadow-root support are not implemented.
- Extend regression, coverage, source, distribution and compatibility tooling and update contributor, privacy, browser and submission documentation. Native installation, upgrade, file-picker import, native print/assistive-technology checks and browser-store acceptance remain pending; older release records retain their original version scope.
